# სასწავლო რესურსი: „რა არის დომენი?“ 🌐
### კომპიუტერული ტექნოლოგიები • V–VI კლასი (10–12 წელი)

ინტერაქტიული, ვიზუალურად მდიდარი და ასაკობრივად ადაპტირებული ვებ-აპლიკაცია / ელექტრონული გაკვეთილის მოდული, შექმნილი სპეციალურად საქართველოს საჯარო და კერძო სკოლების V–VI კლასის მოსწავლეებისთვის და პედაგოგებისთვის.

---

## 🎯 სასწავლო მიზნები და შედეგები
სასწავლო რესურსის დასრულების შემდეგ მოსწავლე:
1. **განმარტავს**, რა არის დომენური სახელი (ინტერნეტ-მისამართი) და როგორ პოულობენ მას მომხმარებლები.
2. **აცნობიერებს** ინტერნეტის „ოქროს სამეულის“ არსს და ანალოგიას: **დომენი** (საფოსტო მისამართი), **ჰოსტინგი** (მიწის ნაკვეთი / 24/7 სერვერი) და **ვებსაიტი** (შენობა ამ ნაკვეთზე).
3. **აღწერს** DNS-ის ფუნქციას: როგორ გარდაიქმნება ადამიანისთვის გასაგები დომენური სახელი კომპიუტერის ციფრულ **IP მისამართად** (მაგ., `123.123.123.123`).
4. **განასხვავებს** დომენის დონეებს („სართულებს“) და იცის, რომ ათვლა იწყება **მარჯვნიდან მარცხნივ** წერტილებით გამოყოფით:
   - **1-ლი დონე (TLD)**: გლობალური (`.com`, `.org`, `.net`), სპეციალური (`.tv`, `.museum`) და ქვეყნის კოდები (`.ge`, `.uk`, `.de`);
   - **მე-2 დონე**: ძირითადი სახელი (მაგ. `skola` ან `avangardhosting`);
   - **მე-3 დონე (ქვედომენი / Subdomain)**: მაგ. `kids` ან `order`.
5. **იცავს ტექნიკურ წესებს**: დასაშვებია მხოლოდ ლათინური ასოები, ციფრები და დეფისი (`-`); მაქსიმალური სიგრძე არ აღემატება 63 სიმბოლოს; იცის საერთაშორისო მარეგულირებელი ორგანიზაცია **ICANN**-ის შესახებ.
6. **განასხვავებს კუთვნილების ფორმებს**: გლობალური დომენების (1–10 წელი, გასხვისების უფლებით) და ქართული `.ge` ზონის რეგულაციას (1 წელი, მხოლოდ ფლობა და სარგებლობა — გასხვისებისა და გაჩუქების უფლების გარეშე).
7. **ავლენს ციფრულ ეთიკასა და პასუხისმგებლობას**: აცნობიერებს, რატომ არის „დომენური მეკობრეობა“ (კიბერსკვოტინგი) მიუღებელი და რატომ არ შეიძლება პირადი საიდუმლოებების (პირადი ნომერი, პაროლები) გამოყენება საჯარო მისამართებში.

## 🎨 პედაგოგიური და დიზაინ-პრინციპები
- **სკაფოლდინგი (მარტივიდან რთულისკენ):** გაკვეთილი იწყება თვალსაჩინო ცხოვრებისეული ანალოგიებითა და თამაშით, შემდეგ გადადის ფორმალურ ტერმინოლოგიასა და ტექნიკურ წესებზე.
- **განმავითარებელი უკუკავშირი:** შეცდომის დაშვებისას მოსწავლეს ეძლევა მიმართულება და მინიშნება („დაფიქრდი...“) და არა უბრალო დასჯა („არასწორია!“).
- **ვიზუალური და აუდიო სტიმულირება:** მასკოტი „დოტი“, ინტეგრირებული Web Audio API (ხმოვანი ეფექტები აუდიო-ფაილების გარეშე), კონფეტის ფოიერვერკი და ვარსკვლავების პროგრესი.
- **ინკლუზიურობა და ხელმისაწვდომობა:** მაღალი კონტრასტი, დიდი და მარტივად წასაკითხი შრიფტი (`Fira GO`), სრული მხარდაჭერა კომპიუტერებზე, სმარტ-დაფებსა და ტაბლეტებზე.

## 🚀 როგორ გავუშვათ?
რესურსი არის **სრულად ავტონომიური (Offline Ready)** და არ საჭიროებს ინტერნეტ-სერვერს, ინსტალაციას ან რაიმე ბიბლიოთეკას.

1. გახსენით საქაღალდე: `c:\Users\user\Desktop\დომენი`
2. ორჯერ დააჭირეთ ფაილს: **`index.html`**
3. აპლიკაცია მყისიერად გაიხსნება ნებისმიერ ბრაუზერში (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

## 👩‍🏫 საგაკვეთილო სცენარი (რეკომენდაცია მასწავლებლისთვის - 45 წთ)
- **00–10 წთ (გამოწვევა):** მასკოტ დოტის გაცნობა, DNS სიმულატორის ცდა (მოდული 1) და ანალოგიების განხილვა.
- **10–20 წთ (პრაქტიკული აღმოჩენა):** „ააწყვე შენი ვებსახლი“ და „სართულების“ გარჩევა მარჯვნიდან მარცხნივ (მოდულები 2 და 3).
- **20–30 წთ (დისკუსია და ეთიკა):** ქართული და გლობალური დომენების შედარება, ეთიკური დეტექტივის ქეისების განხილვა (მოდული 4).
- **30–38 წთ (ლაბორატორია):** საკუთარი დომენის მოფიქრება და შემოწმება (მოდული 5).
- **38–45 წთ (შეჯამება & აღიარება):** შემაჯამებელი ქვიზის გავლა, სერტიფიკატების მიღება და ამობეჭდვა (მოდული 6).
